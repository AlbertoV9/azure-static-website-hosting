# Azure Static Website Hosting
In this project I deploy a static website on Azure Static Web Apps. I configure a custom domain in Azure DNS, secure it with HTTPS, protect it through Azure Front Door and Azure WAF, and automate deployments with Github Actions.

## Version 1 - use of the storage account as the hosting service

### Architecture
 User -> Azure Storage Account -> Static Website Hosting

 ### Technologies 
 - Azure Storage Account
 - ARM Templates
 - Git
 - Github
